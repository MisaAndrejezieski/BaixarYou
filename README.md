# 📥 BaixarYou

Baixe vídeos do YouTube com interface gráfica simples e moderna.

## ✨ Funcionalidades

- Baixar vídeos em 4 qualidades (Best, 1080p, 720p, 480p)
- Extrair áudio para MP3
- Barra de progresso com velocidade
- Interface moderna (CustomTkinter)
- Suporte a cookies.txt (evita bloqueios)

## 🚀 Como Usar

1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python main.py`
4. Cole a URL do YouTube e clique em "BAIXAR"

## 📦 Dependências

- Python 3.8+
- yt-dlp
- customtkinter
- FFmpeg (opcional, para melhor qualidade)

## ⚠️ Aviso Legal

Use apenas para conteúdo que você tem permissão para baixar.
